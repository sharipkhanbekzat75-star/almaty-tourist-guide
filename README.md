# Almaty Tourist Guide

Туристерге арналған Алматы қаласының гид қосымшасы. Қосымша қонақтарға қаладағы көрікті жерлерді табуға, олар туралы ақпарат алуға және картада маршрут құруға көмектеседі. Жоба қаланың көрнекті орындарымен танысуды ыңғайлы әрі жылдам етуге арналған.

## Мақсаты

Туристердің Алматыда көрікті жерлерді өз бетімен тауып, маршрутты оңай жоспарлауына мүмкіндік беретін гид қосымшасын жасау.

## Пайдаланушылар

- Турист
- Әкімші (контентті басқарады)

## Талаптар

1. Турист көрікті жерлерді атауы немесе санаты бойынша іздейді.
2. Турист көрікті жердің сипаттамасын, суреттерін және жұмыс уақытын қарайды.
3. Турист өзінің орналасқан жерінен таңдалған көрікті жерге дейінгі маршрутты картада құрады.
4. Турист ұнаған көрікті жерлерді таңдаулыларға қосады.
5. Турист қосымшаны қазақ, орыс және ағылшын тілдерінде қолданады.
6. Әкімші жаңа көрікті жерлерді қосады, өзгертеді және жояды.
7. Жүйе жаңа деректерді тексеріп, дұрыс емес сұрау кезінде қате туралы хабар көрсетеді.
8. Жүйе көрікті жерлер туралы деректерді деректер қорында сақтайды.
